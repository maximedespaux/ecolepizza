# Signature via documents

1. Devis (O, S ou E)
2. Contrat (O, S) || Convention (O, E)
3. Invitation (O)
4. Droit image (O, S)
5. Feuille emargement (O, S)
6. Certificat  de realisation (O)
7. Si OPCO attestation d'assiduite (O, E)
8. Evaluation de satisfaction (S)

NOTE pour les signatures demandées sur les documents :

- O = Signé par l'organisme de formation
- S = Signé par le stagiaire
- E = Signé par l'entreprise
